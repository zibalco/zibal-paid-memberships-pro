# Zibal Paid Memberships Pro

درگاه پرداخت زیبال برای افزونه Paid Memberships Pro.

این افزونه امکان دریافت پرداخت عضویت از طریق زیبال را به Paid Memberships Pro اضافه می‌کند و برای سایت‌هایی مناسب است که فروش اشتراک یا سطح عضویت دارند.

## پیش‌نیازها

- WordPress
- افزونه Paid Memberships Pro
- حساب و مرچنت فعال زیبال

## نصب

1. پوشه `zibal-paid-memberships-pro` را در مسیر `wp-content/plugins` قرار دهید، یا فایل ZIP افزونه را از بخش افزونه‌های وردپرس نصب کنید.
2. افزونه را از بخش افزونه‌های وردپرس فعال کنید.
3. از تنظیمات پرداخت Paid Memberships Pro، درگاه `زیبال` را انتخاب کنید.
4. واحد پولی مورد نظر را روی ریال یا تومان تنظیم کنید.
5. برای تست، محیط پرداخت را روی حالت تست قرار دهید. برای استفاده واقعی، محیط زنده را انتخاب کرده و مرچنت زیبال را وارد کنید.

## نکته

پس از انجام پرداخت، نتیجه تراکنش در سفارش ثبت می‌شود و اطلاعات مدیریتی پرداخت فقط در بخش سفارش برای مدیر سایت قابل مشاهده است.
