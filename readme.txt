درگاه پرداخت زیبال برای Paid Memberships Pro.

== Description ==

Zibal Paid Memberships Pro درگاه پرداخت زیبال را به افزونه Paid Memberships Pro اضافه می‌کند.

با این افزونه می‌توانید پرداخت سطح‌های عضویت را از طریق زیبال دریافت کنید. برای استفاده از افزونه، Paid Memberships Pro باید روی سایت فعال باشد و مرچنت زیبال خود را در تنظیمات پرداخت وارد کنید.

== Installation ==

1. افزونه را از بخش افزونه‌های وردپرس نصب کنید یا پوشه `zibal-paid-memberships-pro` را در مسیر `/wp-content/plugins/` قرار دهید.
2. افزونه را فعال کنید.
3. به تنظیمات پرداخت Paid Memberships Pro بروید.
4. درگاه `زیبال` را انتخاب کنید.
5. محیط تست یا زنده را انتخاب کرده و مرچنت زیبال را وارد کنید.

= آیا Paid Memberships Pro لازم است؟ =

بله. این افزونه به عنوان درگاه پرداخت برای Paid Memberships Pro کار می‌کند.
