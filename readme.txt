درگاه پرداخت زیبال برای Paid Memberships Pro.

== Description ==

Zibal Paid Memberships Pro درگاه پرداخت زیبال را به افزونه Paid Memberships Pro اضافه می‌کند.

با این افزونه می‌توانید پرداخت یک‌بارهٔ سطح‌های عضویت را از طریق زیبال دریافت کنید. برای استفاده از افزونه، Paid Memberships Pro باید روی سایت فعال باشد و مرچنت زیبال خود را در تنظیمات پرداخت وارد کنید.

این اتصال از پرداخت دوره‌ای پشتیبانی نمی‌کند و سطح recurring را پیش از ایجاد تراکنش متوقف می‌کند. عضویت‌های یک‌باره همچنان از داخل PMPro قابل لغو هستند، اما subscription خودکاری برای تمدید یا لغو در زیبال ساخته نمی‌شود.

این درگاه فقط از واحد پول ریال (IRR) و تومان (IRT) پشتیبانی می‌کند و سایر واحدهای پولی را پیش از ساخت درخواست پرداخت رد می‌کند.

== Installation ==

1. افزونه را از بخش افزونه‌های وردپرس نصب کنید یا پوشه `zibal-paid-memberships-pro` را در مسیر `/wp-content/plugins/` قرار دهید.
2. افزونه را فعال کنید.
3. به تنظیمات پرداخت Paid Memberships Pro بروید.
4. درگاه `زیبال` را انتخاب کنید.
5. محیط تست یا زنده را انتخاب کرده و مرچنت زیبال را وارد کنید.

== Frequently Asked Questions ==

= آیا Paid Memberships Pro لازم است؟ =

بله. این افزونه به عنوان درگاه پرداخت برای Paid Memberships Pro کار می‌کند.

= آیا می‌توانم پرداخت تست انجام دهم؟ =

بله. ابتدا محیط پرداخت را روی حالت تست قرار دهید و پس از اطمینان، حالت زنده را فعال کنید.

= آیا روی PHP 5.6 کار می‌کند؟ =

بله، خود درگاه با PHP 5.6 تا PHP 8.5 سازگار است؛ اما نسخه Paid Memberships Pro نیز باید از PHP نصب‌شده پشتیبانی کند. برای نمونه PMPro 2.12.10، 3.0.6 و 3.2.2 روی PHP 5.6 قابل استفاده‌اند، در حالی که PMPro 3.8.4 حداقل PHP 7.4 می‌خواهد.
